## 3-39
**Point:** 从⋯⋯起 and 离⋯⋯还 patterns expressing "from [time/event]" or distance/duration
**Covers:** Sentences with 从 + time/event + 起/LC or 以后/LC, or 离 + event/noun + 还/AD + 有/VE or 远/VA, expressing a starting point in time or remaining distance/duration
**Does not cover:** Other uses of 从 (extraction, causation, perspective); 起来 as direction complement or aspect marker; 看起来 appearance; 一起 meaning "together"; 比起 comparisons

```rule
match: 从/P _ ... 起/LC
match: 从/P _ ... 以后/LC
match: 离/P _ ... 还/AD 有/VE
match: 离/P _ ... 还/AD 远/VA
unless: 看/VV 起来/VV
unless: _ 起来/VV
unless: 一起/AD
unless: 比/VV 起/VV
unless: 从不/AD
unless: 从小/AD
unless: 从事/VV
unless: 从来/AD
```

**Notes:** The rule matches the four main patterns of this grammar point: (1) 从 + time/event + 起, (2) 从 + time/event + 以后, (3) 离 + event + 还有, (4) 离 + event + 还远. The unless clauses exclude confusable patterns like 看起来 (appearance), other 起来 uses (direction complement), 一起 (together), 比起 (comparison), and adverbial uses of 从 (从不, 从小, 从事, 从来). The patterns use `...` to allow intervening words between the preposition and the key postposition.
