The warm-up exercise asks students to match pictures (labeled A–F) to words. The pictures are described as: row 1: A=cars parked, B=clothes on hangers, C=books; row 2: D=apples, E=bookstore interior, F=shopping mall interior.

- 苹果 (apples) → D
- 车 (car) → A
- 衣服 (clothes) → B
- 商店 (shopping mall/store) → F
- 书店 (bookstore) → E
- 英语书 (English books) → C

For the picture description exercise (Exercise 3), the blanks are open-ended (students describe pictures themselves), except where context from the dialogues provides a clear answer:

- "桌子 上___是 张 先生 的 东西。" — from Text 3: "这些都是王方的东西" and Note 4 example (3): "这些都是王方的东西", the pattern uses "都". The picture shows shopping bags, and the sentence parallels "这些都是王方的东西." So the blank is "都".
- "丽丽买了___衣服。" — from Text 3: "她买了不少衣服", the blank is "不少".
- "妈妈 去 商店 买了___。" — open-ended, no single correct answer derivable from text.
- "她 下午 去 学___了。" — open-ended, no single correct answer derivable from text.
